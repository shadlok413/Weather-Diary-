Weather Diary (Дневник погоды)
### Автор: "Кузнецов Дмитрий"]

### Weather Diary - Это простое Python-приложение с графическим интерфейсом (GUI) для ведения личного дневника погоды. Оно позволяет фиксировать погодные условия за разные дни, сохранять историю в файл и быстро находить нужные записи.

### Возможности программы
✅ - Добавление записей: Вводите дату, температуру, текстовое описание (например, «Ясно» или «Дождь») и отмечайте наличие осадков.
✅ - Просмотр истории: Все добавленные записи отображаются в удобном списке.
✅ - Фильтрация данных:Поиск записей за конкретную дату, поиск записей с температурой выше заданного значения.
✅ Сохранение данных: Вся информация надёжно хранится в файле weather.json. Данные не потеряются после закрытия программы.
✅ Проверка ввода: Программа не даст сохранить запись, если дата или температура введены в неверном формате.
 ### Технологии
Язык: Python 3.15
Интерфейс: Tkinter (стандартная библиотека для создания оконных приложений).
Хранение данных: JSON (удобный формат для сохранения структурированной информации).
 ### Как запустить
Установите Python с официального сайта (версии 3.6 или новее), если он ещё не установлен: python.org.
Скачайте или склонируйте этот репозиторий на свой компьютер.
Откройте папку проекта в терминале или командной строке.
Запустите приложение командой: python diary_app.py
### Примеры использования
Добавление записи:
В поле «Дата» введите: 2024-05-06.
В поле «Температура» введите: 18.5.
В поле «Описание» введите: Переменная облачность.
Нажмите кнопку «Добавить запись».
Фильтрация по дате:
Введите в поле поиска дат 2024-05-06.
Нажмите кнопку «Найти». В списке останутся только записи за этот день.
Фильтрация по температуре:
Введите в поле поиска температуры число 15.
Нажмите кнопку «Найти». В списке отобразятся все дни, когда было теплее 15 градусов.
